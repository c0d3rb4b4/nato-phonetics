## Diagnosis and build decision

The read-only copy of the Run 35 AVD reproduced the error on the installed APK with SHA-256 `c30ca0d912e1bd56bd895f5f5d6790525036a419a09f3f419d9b57429a1e4ecb`. PackageManager found Google TTS. The local generated PackageList registered only the core, AsyncStorage and safe-area packages. Neither DEX contained the TTS module descriptor. A fresh React Native CLI config discovered the package, while the cached Gradle autolinking config omitted it entirely. The origin of the cache discrepancy is unknown. The separately archived development download `12e6030c653ef2e131a4f18ace8255ec81e0ef0332452d87d6b297661247cd8d` does contain the descriptor. The demonstrated omission is specific to the inspected local APK.

Reforecast at that boundary: compile the pinned library's Java sources in the application source set and register its package directly. The Android CLI override prevents duplicate registration on a clean build. The iOS pod remains discoverable. This makes a missing package a compile error in MainApplication. No JS speech timeout, provider selection, network policy or persisted data changes.

A same-guest control narrowed the failure further. Installing the archived development download with `adb install -r` and cold-opening Voice Select exposed “Showing 17 of 17 English voices”, including local and network voice IDs. Several Run 35/36 observations were made against the APK missing the bridge, so they do not establish an engine fault.

The first Gradle attempt could not find CMake 3.30.5 because PATH selected 4.1.0. The retry prepended `artifacts/run34/cmake-tool/cmake-3.30.5-windows-x86_64/bin`. The exact task from `android/` was `gradlew :app:verifyDevelopRenderer :app:assembleDevelop -PreactNativeArchitectures=x86_64 --max-workers=2`. The Develop build used the host Node 24.15.0. Its bundled JS matches the original APK. The separate shared checks used the project's Node 22.23.0 and npm 10.9.4. Lint and typecheck passed. The suite passed 172 tests and skipped one Windows symlink fixture. All 12 native adapter tests passed.
