**Parked P10 tooling follow-up.** The composition driver's 120-second host timeout can close ADB while device-side instrumentation is still running. The active session has no invocation token. Android's package-wide force-stop could interrupt a replacement test between observing its PID and stopping it. A late device write after host cleanup has not been observed in these runs. Re-enter if a timeout leaves a session changing the restored scale or keyboard, or when adding concurrent instrumentation on the same device. Exercise a deliberately delayed disposable test, give it a unique cancellation token, and wait for that session's acknowledgment before restoring caller settings.
