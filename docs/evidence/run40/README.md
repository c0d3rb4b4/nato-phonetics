## Android implementation

On Android the quiz offers a spoken code-word round with the same symbol sets, review scope and normalized scoring as typed recall. Start inspects local service availability. On API 33+ the adapter checks installed en-US models when the provider supports the query. Permission is requested at use, and granting it leaves the microphone idle until a fresh Start. Recognition always uses the on-device factory. The learner can stop, retry, edit, or type in the same question. A recognized word is only an in-memory draft. Navigation and lifecycle changes cancel owned capture, provider callbacks carry a request identity, and both the provider and controller bound waits. An outstanding utterance must stop successfully before the microphone opens. A learner who has never played audio can record even if the separate synthesis engine is missing. The app requests an optional microphone hardware feature and adds no service dependency.
