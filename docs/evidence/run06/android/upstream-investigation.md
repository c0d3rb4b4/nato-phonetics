# Native text-layout investigation

17 November 2026. Actual Android captures establish stale enlarged ordinary-text heights. Metrics refresh, a diagnostic font-layout feature flag and explicit surface layout requests did not establish a complete repair. The final platform report identifies which code is retained and which candidates are diagnostics.

An initial source-reading hypothesis blamed a clean root when only the font multiplier changed. **That diagnosis is not confirmed.** It considered `RootShadowNode::clone`, descendant invalidation and child replacement, but initially omitted the root's Yoga-style update path.

Checking the complete installed 0.81.5 path withdrew that hypothesis: `RootProps.cpp` clones with default `ViewProps`; `YogaLayoutableShadowNode::layoutTree` previously wrote root min/max constraints into Yoga styles; the clone's `updateYogaProps` detects that style difference and dirties the root. No C++ regression was run to establish the remaining cause, and adding another root-dirty call is not a demonstrated repair.

The upstream [issue 59927](https://github.com/react/react-native/issues/59927) describes a similar hypothesis on newer iOS/Fabric versions. A [follow-up with C++ test observations](https://github.com/react/react-native/issues/59927#issuecomment-6808678347) says its proposed root-dirty patch had no effect on the tested main revision: cloning already dirtied the root through style differences. It instead points to [PR 59383](https://github.com/react/react-native/pull/59383) as a candidate for a different dirty-subtree problem. These upstream reports concern other versions/platforms and are investigation leads, not verification of a NATO Phonetics fix.

Next engineering work must reproduce and isolate the exact RN 0.81.5 invalidation/cache path with an executable regression before choosing a backport or dependency update. The app currently consumes the prebuilt ReactAndroid artifact; editing installed C++ source alone cannot change its APK. A native backport needs a reproducible patched source build and fresh runtime evidence. Do not replace that work with arbitrary remounts, changed typography, disabled accessibility scaling or relaxed screenshot tolerances.
