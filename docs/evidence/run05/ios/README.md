[33 original screenshots and metadata](../screenshots/ios/metadata.json) retain capture timestamps, hashes, actual device/scale/theme, and inspection details. XCTest PNGs can have portrait encoded dimensions with EXIF orientation 8; displayed landscape dimensions are explicitly recorded and analysis uses `autoOrient()`. No screenshot pixels were rewritten. The five reference images were independently inspected; J, N, U, W, Y and Z appear complete. Scroll-edge fragments are expected viewport clipping and are excluded from reference/raster eligibility. All three resize screenshots were inspected; the Home overlap remains an explicit open finding.

Raster evidence compares retained image ink against outlines from the exact bundled fonts. It enforces the specified one-pixel edge/baseline rounding plus one additional pixel of glyph antialias fringe; it does not widen the baseline tolerance. The iOS Release probe does not independently expose raw native baseline events, so these are actual frame/raster observations, not a claim that native event baselines were directly sampled. Alpha analysis explains the earlier solid-threshold 1.470 px tablet top edge: a row containing alpha 0.6504 was excluded by that threshold; actual top support is within 0.470 px. All 26×3 parts are required in combined phone/reference coverage, rather than inferring completeness from a nonempty result.
